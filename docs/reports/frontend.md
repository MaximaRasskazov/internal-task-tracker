# Frontend: первая поставка T07

Дата: 4 ноября 2026. Ветка: develop-front. Изменения еще не объявлены интегрированными.

## Реализовано

Vue 3 / TypeScript / Vite, PrimeVue 4, Pinia и Vue Router. Одна светлая тема:
цветные акценты проектов, мягкий фон, читаемые поверхности, мобильное меню.
Визуальный ориентир команды — Битрикс24 «Зефир»; это самостоятельная тема трекера.

Вход, регистрация, восстановление cookie-сессии через /auth/me, выход,
ограничение повторного входа по Retry-After, безопасный адрес возврата.
Проекты с серверной пагинацией, создание проекта по роли, доски и участники,
создание доски владельцем/admin, просмотр серверного BoardSnapshot.

API DTO генерируются из OpenAPI. JWT остается в HttpOnly cookie, CSRF хранится
в памяти; сетевые ошибки записи не вызывают автоматического повторения.
Просроченные ответы старой страницы игнорируются. Права обновляются на переходах
и при фокусе окна. Страницы загружаются отдельными chunks.

Добавлены типизированные операции задач; панель справа и на весь мобильный экран;

переносятся только измененные пользователем поля, остальные берутся с сервера.
Сетевой сбой блокирует повторную запись до проверки результата. Операции отправляются
по одной. Доска не принимает снимок ниже подтвержденной revision.

Добавлены тесты PATCH/null/дат, прав удаления, конфликтов, сетевого сбоя,

## Этап 4 — WebSocket-синхронизация (4 ноября 2026)

Добавлен useBoardRealtime: cookie/Origin, connection.ready → HTTP snapshot,
максимальная board_revision, дедупликация event_id, heartbeat watchdog 35 секунд,
reconnect с экспоненциальной задержкой и jitter, online/offline и cleanup при уходе.
Сокет не отправляет бизнес-команды. Повторяются только чтения; записи не переигрываются.
После 4401/4403/4404 повторы прекращаются; при 4401 очищается сессия и открывается вход.
При непрозрачном отказе handshake доступ дополнительно проверяется HTTP-запросом.

До синхронизации/при offline новые записи задач, комментариев и тегов заблокированы.
При временном обрыве видимый снимок и черновики сохраняются. Открытая чистая форма
принимает более новую задачу; изменённая локально предлагает явную сверку без потери
черновика. Права и окончательная версия по-прежнему проверяются сервером.

Проверено: 54 теста в 9 файлах, typecheck, lint, api:check, production build и
format:check — успешно. Новые тесты покрывают ready/snapshot, дубликаты, гонки revision,
ошибки чтения, heartbeat timeout, reconnect, терминальные коды, cleanup, удалённые
правки и блокировку записи тегов offline. Зависимости и backend не менялись.

Docker и npm run dev агентом не запускались. Работа с реальным сервером в двух
сессиях и браузерная приёмка остаются пользователю: frontend/README.md, этап 4.
Следующая поставка — перенос задач между колонками и изменение порядка (DnD).

## Этап 5 — перенос и порядок задач (4 ноября 2026)

Добавлены KanbanBoard и MoveTaskDialog: нативное перетаскивание перед карточкой,
в конец/пустую колонку и выбор колонки/положения через отдельную кнопку для клавиатуры
и touch. Payload использует column_id, before_task_id и captured expected_version.
Самоперенос, прежнее место и несуществующие якоря не отправляют запись.

useTaskMove хранит только предварительное отображение, не изменяя серверный снимок.
Более свежая версия задачи не заменяется старым предпросмотром. После ответа выполняется
чтение не ниже подтверждённой revision. При конфликте/неопределённой ошибке предпросмотр
снимается, запись не повторяется; новые переносы требуют проверки порядка и явного
подтверждения пользователя. На доске допускается один незавершённый перенос.

Проверено: 67 тестов в 10 файлах, typecheck, lint, api:check, build и format:check —
успешно. Покрыты ID-якоря, порядок, неизменность снимка, offline, конфликты, повторные
запросы, отстающий снимок, native drop и отдельная кнопка переноса. Для компонента
PrimeVue Select добавлен matchMedia mock в тестовом окружении jsdom.

## Этап 6 — поиск и комбинируемые фильтры (5 ноября 2026)

а якорь переноса выбирается по ID видимой карточки. Скрытые задачи остаются
в полном порядке. После переноса из выборки показывается пояснение.
